# Tech stack and why

Vite 5 produces static output suitable for Vercel; React 18 and strict TypeScript provide reusable typed screens; Zustand is intended for persistent demo state; React Router supports direct URLs; Framer Motion provides optional motion; date-fns supports calendar logic; lucide-react is used sparingly; self-hosted Fraunces/Hanken/IBM Plex Mono establish the visual voice; Vitest covers pure rules. Tailwind is omitted in the current implementation in favor of authored CSS tokens, avoiding a utility layer for this small prototype. No backend/auth is intentional for assessment scope, not production readiness. Next.js adds server features not needed for static demo; Redux is heavier than needed; UI kits undermine the bespoke design; chart libraries are unnecessary for small custom SVG charts; Firebase would introduce real backend scope.
