# Tech stack and why

Sajag is a static React single-page prototype built with React 18, TypeScript, and Vite 6.4.5. React state drives the demo workflows, while browser `localStorage` persists this one-device demo when browser storage is available. The app uses authored CSS rather than a component kit so the Sajag visual identity and compact operational layouts remain custom. Framer Motion handles small interface transitions and honors reduced-motion preferences; Lucide supplies interface icons. Self-hosted Newsreader and Manrope establish an editorial-meets-operations voice, with IBM Plex Mono for measurements. Vitest covers domain rules and React workflow interactions in jsdom; there is no browser-based end-to-end suite.

There is no backend, shared database, authentication, server authorization, or service worker. The Vercel deployment is therefore a reviewable prototype only. `date-fns`, Zustand, and React Router are not part of the current app implementation. No environment variables are required for the static demo.
